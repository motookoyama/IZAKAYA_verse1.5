# Point Check Sheet

## 対象
- タイトル: 転生裁判
- 種別: region
- 段階: prototype

## この企画の核
- 転生希望者がAI裁判官に審査されるリージョン

## 人間が見るべき急所
- [ ] リージョン体験が一言で説明できるか — 初見でも何を体験する場所か分かる。
- [ ] キャスト配置に意味があるか — 登場キャラがリージョンの体験やルールに接続している。
- [ ] メインビジュアルと売り文句が一致するか — 画像と紹介文から同じ世界観が伝わる。

## AIが先に確認できる項目
- [ ] 必須フィールドが揃っているか — title, content_type, target_phase, concept_text または narrative_output が存在する。
- [ ] 判定欄が PASS / REPAIR / HOLD に限定されているか — 却下を使わず、allowed_judgements が3種に固定されている。
- [ ] リージョン用の構造が確認できるか — 概要、ルール、体験導線、タグ、ビジュアル方向のいずれかが構造化されている。

## 合格ライン
- リージョン体験が一言で伝わり、次に確認すべき画像・V2カード・売り文句の焦点が分かること。

## 判定
- [ ] PASS：次へ進める
- [ ] REPAIR：修正メモを残す
- [ ] HOLD：素材として保留
