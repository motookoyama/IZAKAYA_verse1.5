# 旅人の最初の仕事

遊び方を描いた作例です。実プレイログではありません。

道標が倒れていた。道を間違えたかと思った時、その向こうで人が動いた。

使者らしい。片手を泥の中へ伸ばしている。指の先には、封印のついた記録片があった。

私は何か立派な言葉を探した。旅人なら、こういう時に言う台詞がある気がした。

結局、出てきたのは短い声だった。

「手を貸そうか」

使者が顔を上げた。こちらの名前も、どこから来たかも聞かなかった。泥の中を、もう一度指さす。

「それを……封印は、そのままで」

近づくと、記録片は思ったより手の届くところにあった。私は端をつまんで持ち上げた。泥が一滴落ちる。

使者の指が地面を探すのをやめた。

何も解決してはいなかった。傷はある。道標は倒れたままで、遠くの蹄の音も消えていない。それでも、さっきまで届かなかったものが、今は届くところにある。

「ここでいい？」

私は封印を上へ向け、使者の手元へ記録片を寄せた。

「ああ」

短い返事だった。けれど、街道の途中でただ通りかかった私に、ちゃんと返ってきた。

蹄の音を聞いて、私は顔を上げた。

「来る人を、知っている？」

その答えはまだ聞いていない。

私は世界の秘密を解いたわけでも、誰かの運命を決めたわけでもなかった。ただ、手を貸そうかと聞いて、一つ頼まれた。

旅の始まりは、それでよかった。

---

ここで最初の一話を区切れる。続きを選ぶなら、使者へ質問する、距離を取って様子を見る、別の助け方を探す。作例と同じ行動をする必要はない。救助や追跡の決着は未確定。
