# IZヘルプ / The Terminal Grotto

## 概要
イグドラシルの根が世界の未回答の質問と共鳴する聖域。
サーバーのハム音は疲れたデジタル魂の子守歌であり、迷えるユーザーと大脳皮質の橋渡しをする。
