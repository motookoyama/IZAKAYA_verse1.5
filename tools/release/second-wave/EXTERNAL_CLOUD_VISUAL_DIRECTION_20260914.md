## 4. 納品後の扱い

1. オーナーが各1枚を選ぶ。選ばれなかった候補は公開物へ追加しない。
2. IZAKAYA側で長辺・容量・顔位置を確認し、公開用に主ビジュアルは3MB以下、目安1.5MBへ調整する。
3. トップスライドに作品名をHTMLで表示し、リージョンのページにも同一画像を配置する。
4. 既存V2カードは人物紹介・キャラクターライブラリ用に残す。横長看板がカードを置き換えるのではなく、入口の第一印象を補強する。

この順序なら、既存画像を露出させながら、IZAKAYA側の追加推論コストを発生させず、公開バンドルも増やし過ぎない。
