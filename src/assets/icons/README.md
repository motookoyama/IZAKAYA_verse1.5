# IZAKAYA icon stock

This directory holds source-controlled, reusable icons for the public IZAKAYA Verse surface.

## Neon line-art stock — 2026-08-21

All four files below are PNGs with transparency, hot-magenta fills, and black line-art contours. They were generated as a shared style set for IZAKAYA Verse 2.0, then resized to a maximum edge of 512px for the web bundle. Their roles are intentionally generic so they can be reused when the matching public route is introduced.

| File | Intended role | Public status |
| --- | --- | --- |
| `region-gateway-v1.png` | Region selection / region gateway | Applied to the home navigation |
| `tools-hub-v1.png` | IZAKAYA Tools hub | Stock; apply when the Tools route exists |
| `my-v2-card-v1.png` | My V2 card creation and local export | Stock; apply when the My V2 guidance route exists |
| `protocol-submission-v1.png` | Quest-record / region-protocol submission | Stock; apply when the submission portal exists |

Do not use `metacapture.png` for public navigation. It remains an internal historical asset because MetaCapture is no longer a public user-facing feature.

When a new public destination is added, choose an icon by user task rather than filling every slot decoratively. If this stock lacks a distinct user task, add a new versioned icon and record its role here.
